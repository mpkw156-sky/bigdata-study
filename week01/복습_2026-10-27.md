## 1. 오늘 배운 개념

### 1-1. `for` 반복문: 리스트에서 하나씩 꺼내기

```python
temps = [21, 25, 19]
for t in temps:
    print(t)      # 21, 25, 19가 차례로 출력
```

### 1-2. 누적 변수 패턴

반복문 **바깥**에서 시작값을 정하고, 반복문 **안**에서 계속 고쳐 나간다.

```python
nums = [2, 3, 4]
product = 1              # ① 시작값 (곱셈은 1, 덧셈·개수는 0)
for n in nums:
    product = product * n  # ② 한 바퀴마다 갱신
print(product)           # ③ 반복이 끝난 뒤 결과: 24
```

| 바퀴 | n | product |
|---|---|---|
| 시작 | – | 1 |
| 1 | 2 | 2 |
| 2 | 3 | 6 |
| 3 | 4 | 24 |

### 1-3. 함수와 `return`

- 함수가 하는 일은 **계산해서 `return`으로 돌려주는 것까지**다.
- `return`이 없으면 함수는 `None`을 돌려준다.
- `print()`는 화면에 찍기만 하고 `None`을 돌려준다. → `return print(...)`는 쓰지 않는다.
- 확인용 `print`는 함수 밖, `if __name__ == "__main__":` 아래에 둔다.

### 1-4. 들여쓰기 = 범위

```python
def total(nums):          # 0칸: 함수 시작
    count = 0             # 4칸: 함수 안
    for n in nums:        # 4칸: 함수 안
        count = count + n # 8칸: for 안 (바퀴마다 실행)

    return count          # 4칸: 함수 안, for 밖 (반복이 다 끝난 뒤 한 번)
```

| `return` 위치 | 결과 |
|---|---|
| 0칸 (함수 밖) | `SyntaxError: 'return' outside function` |
| 8칸 (`for` 안) | 첫 바퀴에서 바로 함수 종료 |
| 4칸 (`for`와 같은 칸) | ✅ 반복이 다 끝난 뒤 실행 |

### 1-5. 터미널 사용법

| 상황 | 프롬프트 | 할 일 |
|---|---|---|
| PowerShell | `PS C:\...>` | Python 코드를 치면 오류. 먼저 `.\.venv\Scripts\python.exe`로 Python을 켠다 |
| Python 대화형 | `>>>` | 한 줄씩 입력. 끝낼 때 `exit()` |
| 블록 입력 중 | `...` | 블록이 끝나면 **빈 줄에서 Enter**를 눌러 `>>>`로 돌아온 뒤 다음 줄 입력 |

## 2. 오늘 틀린 과정 (문제 1. 합계)

| 시도 | 코드의 문제 | 채점 결과 | 배운 점 |
|---|---|---|---|
| ① | 파일을 저장하지 않음 | 미완성 | 채점기는 저장된 파일만 읽는다 |
| ② | `return` 없음 | 미완성 (None 반환) | "None이 반환됨" → `return`부터 확인 |
| ③ | `return`을 0칸에 씀 | SyntaxError | 0칸으로 돌아오면 함수 밖 |
| ④ | `return(print(total(...)))`, 5칸 | RecursionError | 함수 안에서 자기 자신을 부르면 무한 반복 |
| ⑤ | 들여쓰기는 맞췄지만 `return print(total(...))` | RecursionError | `return` 뒤에는 **변수 이름 하나** |
| ⑥ | `return count` (4칸) | ✅ 정답 | |

### 채점 메시지 읽는 법

- `None이 반환됨` → `return`이 있는지, 값을 적었는지
- `SyntaxError` → 표시된 줄의 문법·들여쓰기
- `RecursionError` → 함수가 자기 자신을 부르고 있지 않은지

## 3. 스스로 점검하기

먼저 답을 예상한 다음 펼쳐서 확인하세요.

**Q1.** 다음 코드의 출력은?

```python
def f(xs):
    s = 0
    for x in xs:
        s = s + x
        return s

print(f([4, 5, 6]))
```

<details><summary>정답</summary>

`4` — `return`이 `for` 안에 있어서 첫 바퀴에서 함수가 끝난다.
</details>

**Q2.** 다음 코드의 출력은?

```python
def g(xs):
    s = 0
    for x in xs:
        s = s + x

print(g([1, 2]))
```

<details><summary>정답</summary>

`None` — `return`이 없다.
</details>

**Q3.** 리스트의 값을 모두 곱하는 함수를 만들 때 시작값을 `0`으로 하면 어떻게 될까?

<details><summary>정답</summary>

무엇을 곱해도 0이라서 결과가 항상 `0`이 된다. 곱셈의 시작값은 `1`.
</details>

**Q4.** `>>>`에서 `for` 블록을 입력한 직후 빈 줄 없이 `print(...)`를 치면?

<details><summary>정답</summary>

`SyntaxError: invalid syntax` — 아직 `...` 상태(블록 입력 중)라서. 빈 줄에서 Enter를 눌러 블록을 끝내야 한다.
</details>

**Q5. (직접 코딩)** `sum()` 없이 리스트에 있는 **양수의 개수**를 세는 함수 `count_positive(nums)`를 써 보세요. `[3, -1, 0, 7]` → `2`

<details><summary>힌트</summary>

개수 세기 누적 변수(시작값 0) + 조건문 `if n > 0:`. 문제 4·5에서 쓸 조건문을 미리 연습하는 문제다.
